# =============================================================================
#  RP Interact - Véhicules du menu d'interactions (F1 > Voiture > Spawn)
# =============================================================================
#  UNE LIGNE PAR VÉHICULE, champs séparés par des points-virgules :
#
#    spawn code ; service ; nom affiché ; livery ; extras
#
#  - spawn code  : nom du modèle (celui du dossier stream / de la commande de spawn)
#  - service     : Atlanta Police Department | Georgia State Patrol | Fayette County Sheriff Office | Autres
#                  (les trois premiers vont dans "Police", "Autres" dans la liste "Autres")
#  - nom affiché : ce qui apparaît dans le menu (ex : Atlanta Police Dept / FPIU 2016)
#  - livery      : (facultatif) numéro de la livery activée à l'apparition, vide = livery par défaut
#  - extras      : (facultatif) extras ACTIVÉS à l'apparition, séparés par des virgules (ex : 1,2,5) ;
#                  les autres extras du véhicule sont désactivés. Vide = extras par défaut.
#
#  Les lignes qui commencent par # sont ignorées. Après une modification : "rpi_vehicles" dans la
#  console serveur (ou redémarrage de la ressource) pour relire le fichier.
#
#  Exemples (véhicules du jeu de base, à remplacer par les vôtres) :
# =============================================================================

police3 ; Atlanta Police Department ; Atlanta Police Dept / Interceptor ; 0 ;
police2 ; Atlanta Police Department ; Atlanta Police Dept / Buffalo ; ;
police4 ; Georgia State Patrol ; Georgia State Patrol / Unmarked ; ;
sheriff2 ; Georgia State Patrol ; Georgia State Patrol / Granger ; 0 ; 1,2
sultan ; Autres ; Karin Sultan ;  ;
baller2 ; Autres ; Gallivanter Baller ; ;
