Ancien dossier de données du MDC (versions 1 et 2).

Depuis la version 3, TOUTES les données du MDC sont dans MySQL / MariaDB (ressource oxmysql) :
identités, véhicules, rapports, BOLO, unités, interventions, notes, messages, agents, journal…
(voir le README de rp_mdc, section « Base de données (MySQL) »).

Au premier démarrage avec MySQL, les fichiers de ce dossier (s'ils existent) sont IMPORTÉS UNE SEULE FOIS dans la base :
  identities.json  -> table mdc_identities
  vehicles.json    -> table mdc_vehicles
  reports.json     -> table mdc_reports
  bolos.json       -> table mdc_bolos
Ensuite ils ne sont plus lus ni modifiés : gardez-les comme sauvegarde, ou supprimez-les.

Pour corriger une fiche à la main : modifiez la ligne dans MySQL (colonne data, JSON) puis tapez  mdc_reload  dans la
console serveur.
