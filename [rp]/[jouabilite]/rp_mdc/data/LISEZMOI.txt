Dossier de données du MDC (créé et rempli automatiquement par le serveur).

  identities.json  -> identités enregistrées via "Créations"
  vehicles.json    -> véhicules enregistrés via "Créations"
  reports.json     -> rapports rédigés via "Rapports" (DOT-523, Arrest Report, tickets…)
  bolos.json       -> BOLOs actifs (Recherches -> bouton "BOLOs")

Ces fiches sont PERMANENTES : elles survivent aux déconnexions et aux redémarrages.
Identités et véhicules restent accessibles dans les recherches et dans le registre de
leur créateur ; les rapports dans l'onglet "Rapports" (seul leur auteur peut les modifier).
L'auteur est retrouvé grâce à sa licence Rockstar (champ "createdBy").
Les unités, interventions et incidents ne sont pas enregistrés ici : ils disparaissent au redémarrage.

Le script ne supprime JAMAIS d'entrée, sauf les BOLOs : un BOLO supprimé depuis le MDC (bouton
"Supprimer") est retiré de bolos.json. Pour retirer une autre entrée (cadres uniquement) :
  1. Ouvrez le fichier et supprimez l'objet { ... } voulu (le fichier doit rester un JSON valide).
  2. Tapez  mdc_reload  dans la console serveur (ou redémarrez la ressource).

Si un fichier devient illisible, le MDC bloque les créations/modifications de ce type
plutôt que de l'écraser : corrigez le JSON puis tapez mdc_reload.

ATTENTION : lors d'une mise à jour du script, ne remplacez pas ce dossier.
(Un ancien fichier interventions.json, s'il existe, n'est plus utilisé et peut être supprimé.)
