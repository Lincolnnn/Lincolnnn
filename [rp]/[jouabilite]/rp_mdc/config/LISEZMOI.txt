Blocs de localisation du PLD : blocs.json
==========================================

Le PLD affiche le "bloc" de la zone où se trouve le joueur. Le PREMIER bloc de la liste "blocks" qui contient le
joueur est affiché : placez les petits blocs AVANT les grands qui les englobent. Hors de tout bloc, c'est le bloc le
PLUS PROCHE qui est affiché. "default" n'est utilisé que si "blocks" est vide.

"blocks" est VIDE au départ : ajoutez-y vos blocs. "exemples" n'est jamais lu (modèles à copier dans "blocks").

Deux formes principales (coordonnées x, y du jeu ; la hauteur z n'est pas utilisée) :

  POINT  (une simple coordonnée ; "radius" facultatif, 75 m par défaut) :
    { "name": "400", "type": "point", "coords": [x, y] }
    { "name": "100", "type": "point", "coords": [x, y], "radius": 120 }

  CARRÉ  (4 coordonnées = les 4 coins, dans l'ordre du tour ; pour une grande zone sous un seul bloc) :
    { "name": "1800", "type": "square", "corners": [[x1, y1], [x2, y2], [x3, y3], [x4, y4]] }

Toujours acceptés : cercle ("circle", "center", "radius"), rectangle ("rect", "min", "max"), polygone ("poly",
"points" : autant de coins que voulu).

Option sur chaque bloc : "street": "Nom de la rue" -> le bloc ne vaut que sur cette rue (nom AFFICHÉ par le PLD,
donc celui de config/washington.json, ex. "I-90" et non "Great Ocean Hwy").

Noms des rues, quartiers et villes du PLD : config/washington.json, et rien d'autre (liste : WASHINGTON_CARTE.md).

Trouver des coordonnées en jeu : commande /mdc_pos (console F8) : position actuelle, bloc détecté, ligne "point"
prête à copier et coin de carré.

Plus simple (admins) : /blocs ouvre l'éditeur. Point ou carré, rayon / largeur / hauteur / rotation, visible en jeu
et sur la carte ; "Ajouter le bloc" puis "Copier tout" : les lignes sont prêtes à coller dans "blocks" (une virgule
entre chaque bloc, déjà mise par "Copier tout"). Redémarrer rp_mdc ensuite.

Le fichier doit rester un JSON valide (virgules entre les blocs, pas de virgule après le dernier, pas de
commentaires). Après modification : restart rp_mdc (les joueurs reçoivent le nouveau fichier).
