Position des HUD

Le PLD est toujours affiché (sauf si vous le désactivez) ; le display MDC apparaît dès que vous rejoignez une unité. Le mode placement masque le MDC : déplacez chaque HUD à la souris, la molette l'agrandit ou le rétrécit. Échap ou « Terminer » pour revenir.
