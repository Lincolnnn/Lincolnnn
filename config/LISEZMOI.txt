Blocs de localisation du HUD (PLD) : blocks.json
================================================

Le PLD affiche le "bloc" de la zone où se trouve le joueur. Chaque bloc est une zone
dessinée sur la carte. Le PREMIER bloc de la liste qui contient le joueur est affiché :
placez donc les petites zones précises AVANT les grandes zones qui les englobent.
Hors de tout bloc, c'est le bloc le PLUS PROCHE qui est affiché : le bloc ne disparaît
jamais. "default" n'est utilisé que si le fichier ne contient aucun bloc.

Les blocs fournis sont des EXEMPLES (Mission Row, Legion Square, Sandy Shores, Paleto) :
remplacez-les par les vôtres.

Formats (coordonnées x, y du jeu ; la hauteur z n'est pas utilisée) :

  Cercle    : { "name": "400",  "type": "circle", "center": [x, y], "radius": 80 }
  Rectangle : { "name": "200",  "type": "rect",   "min": [x1, y1], "max": [x2, y2] }
  Polygone  : { "name": "1800", "type": "poly",   "points": [[x1, y1], [x2, y2], [x3, y3], ...] }

Option sur chaque bloc : "street": "Nom de la rue" -> le bloc ne s'applique que sur cette
rue (nom exact affiché par le PLD, sans tenir compte des majuscules).

Trouver des coordonnées en jeu : commande  /mdc_pos  (console F8) : affiche la position
actuelle et le bloc détecté, avec une ligne prête à copier.

Le fichier doit rester un JSON valide (virgules entre les blocs, pas de virgule après le
dernier, pas de commentaires). Après modification : redémarrez la ressource
(ensure mdc_standalone), les joueurs reçoivent automatiquement le nouveau fichier.
